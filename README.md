# Cursor 中文化一键包（v1）

把 Cursor 界面改成中文，包括官方语言包覆盖不到的那部分（侧栏、欢迎页、思考标签、右键菜单）。

适用版本：**Cursor 3.27.22**（其它版本也能用，但部分词条可能对不上，脚本会告诉你哪几条没生效，不会改坏）。

---

## 怎么用（推荐一键，约 1 分钟）

> 开始前：把 Cursor **完全退出**（任务栏右键 → 关闭窗口，托盘里也要退）。

1. 双击 **`0-一键汉化.bat`** —— 自动完成全部汉化：装语言包 → 汉化内置界面文案（**会弹一次 UAC，点「是」**）→ 同步校验和。
2. 重新打开 Cursor。菜单、侧栏、欢迎页、设置页、模型页都是中文了。

也可以手动分步：`1-安装语言包.bat`（只装语言包，不弹 UAC）→ `2-应用汉化.bat`（只汉化界面文案，弹 UAC）。

想确认有没有生效，双击 **`4-检查状态.bat`**，它会打印每部分还剩几条英文。

全程只用 Windows 自带的 PowerShell，**不需要装 Python、Node 或任何其它工具**；不改注册表、不配环境变量。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\patch.ps1" -Mode Apply -CursorDir "D:\你的\Cursor目录"
```

## 它到底改了什么

**第一层：语言包**（改用户目录，可安全卸载）
- 装 `polang233.cursor-language-pack`，译文用微软官方包 + 社区包合并版，共 24,197 条（比社区原版多 255 条、补回 185 条英文漏译）
- 写 `~\.cursor\languagepacks.json`、`~\.cursor\argv.json`（locale=zh-cn）
- 清 `%APPDATA%\Cursor\clp` 语言包编译缓存，让 Cursor 重新生成

**第二层：程序包里的写死文案**（改 Cursor 安装目录，改前自动备份）
- `resources\app\out\vs\workbench\workbench.glass.main.js`（玻璃窗 / Agents 窗口）
- `resources\app\out\vs\workbench\workbench.desktop.main.js`（经典窗口）
- 每处替换都带上下文锚定（如 `label:"File"`），不碰被程序当作逻辑判断的字符串
- **会同步 `product.json` 里的 sha256 校验和**，否则 Cursor 会弹「安装似乎损坏」

## 不会变中文（改不了，不是漏做）

1. **云端下发的推荐卡**（如 `Deploy my prototype`、`Review my database`）：文字在服务器，本地包里搜不到。
2. **模型思考正文**：标签已中文，但思考内容是模型输出。要它中文思考，在 `Cursor Settings → Rules → User Rules` 加一句「始终使用简体中文进行思考与回答」。
3. **你自己的数据**：会话名、仓库名、设备名原样保留。
4. 少量长句提示（Tips 正文）仍是英文。

## 出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 弹「Cursor 安装似乎损坏」 | 校验和没同步（多半是手动改了包） | 重跑 `2-应用汉化.bat`，它会同步校验和 |
| 界面还是英文 | 没重启，或语言包映射没生效 | 完全退出 Cursor 再开；不行就重跑 `1-安装语言包.bat` |
| 界面白屏 / 打不开 | 词条与你的版本不匹配（少见） | 双击 `3-还原英文.bat`，再把 Cursor 升级到 3.27.22 后重试 |
| 改完提示权限不足 | 没点 UAC 的「是」 | 重新双击，UAC 选是 |
| 只想撤掉中文 | — | `3-还原英文.bat` 还原程序包；再在 Cursor 扩展面板里卸载 `polang233.cursor-language-pack` |

## 风险说明

- 第二层是**修改 Cursor 程序文件**。改前会自动备份成 `*.zhbak`，还原脚本就是把它拷回去。
- **Cursor 每次升级都会覆盖程序文件**，升级后中文会掉一部分，重跑一次 `2-应用汉化.bat` 即可。
- 本包不含任何联网行为，除了第 1 步可能尝试从扩展市场装语言包（装不上会自动改用包内自带的那份）。
- 自己用没问题；如果要分发，请保留本 README 与原作者信息。
