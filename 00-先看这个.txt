========================================
 Cursor 中文化一键包 v1  —— 先看这里
========================================

适用版本：Cursor 3.27.22（Windows）
不需要装 Python / Node，只用 Windows 自带的 PowerShell。
全程不改注册表、不配环境变量。

----------------------------------------
 推荐：一键搞定（约 1 分钟）
----------------------------------------

第 0 步：把 Cursor 完全退出
         （任务栏右键关闭窗口，右下角托盘里也要退出）

第 1 步：双击  0-一键汉化.bat
         自动完成全部汉化：
         ① 装中文语言包（24,197 条合并译文，无需管理员）
         ② 汉化 Cursor 内置界面文案（会弹一次 UAC，点「是」，
            改前自动备份成 *.zhbak）
         ③ 同步校验和，防止报「安装似乎损坏」

第 2 步：重新打开 Cursor，界面就是中文了。

----------------------------------------
 也可以手动分步（可选）
----------------------------------------

第 1 步：双击  1-安装语言包.bat  只装语言包，不弹 UAC。
第 2 步：双击  2-应用汉化.bat   只汉化内置界面文案，弹 UAC。
第 3 步：重新打开 Cursor。

想确认效果：双击  4-检查状态.bat
         它只读取检查，什么都不改，会打印还剩几条英文。
还原英文：双击  3-还原英文.bat

----------------------------------------
 出了问题怎么办
----------------------------------------

1) 弹「Cursor 安装似乎损坏」
   → 校验和没同步。重跑一次 2-应用汉化.bat，它会自动同步。

2) 界面还是英文
   → 没重启，或语言包映射没生效。完全退出 Cursor 再开；
     还不行就重跑 1-安装语言包.bat。

3) 界面白屏 / 打不开
   → 版本词条对不上（少见）。双击 3-还原英文.bat，再把
     Cursor 升级到 3.27.22 后重试。

4) 只想全部撤掉
   → 双击 3-还原英文.bat 还原程序包；
     再到 Cursor 扩展面板卸载 polang233.cursor-language-pack。

5) 提示拒绝访问 / 权限不足
   → 说明没点 UAC 的「是」，或者用了管理员以外的受限账户。
     重新双击，UAC 选「是」。

6) 提示找不到 Cursor 安装目录
   → 手动指定，例如：
     powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\patch.ps1" -Mode Apply -CursorDir "D:\你的\Cursor目录"

----------------------------------------
 它改了哪些东西
----------------------------------------

用户目录（可撤销，不需要管理员）：
   ~\.cursor\extensions\      中文语言包扩展
   ~\.cursor\languagepacks.json   99 条译文映射
   ~\.cursor\argv.json        locale = zh-cn
   %APPDATA%\Cursor\clp\      清掉语言包编译缓存

Cursor 程序目录（改前自动备份 .zhbak）：
   resources\app\out\vs\workbench\workbench.glass.main.js    玻璃窗（Agents 窗口）
   resources\app\out\vs\workbench\workbench.desktop.main.js  经典窗口
   resources\app\product.json                                 同步 sha256 校验和

注：Cursor 每次升级都会覆盖程序文件，中文会掉一部分，
    升级后重跑一次 2-应用汉化.bat 即可。

----------------------------------------
 汉化不了的部分（不是漏做）
----------------------------------------

- 云端下发的推荐卡（如 Deploy my prototype、Review my database）：
  文字在服务器上，本地包里搜不到。
- 模型「思考正文」：标签已中文，但思考内容由模型输出。
  想让它中文思考，在 Cursor Settings -> Rules -> User Rules 加一句：
  「始终使用简体中文进行思考与回答」。
- 你自己的数据：会话名、仓库名、设备名原样保留。
